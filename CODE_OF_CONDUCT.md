# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short: be respectful and constructive, assume good faith, and keep discussions about
the work.

Unacceptable behaviour can be reported to the maintainer at duceppemo@gmail.com. Reports are handled
confidentially.
